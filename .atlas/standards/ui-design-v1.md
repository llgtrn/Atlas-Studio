# Atlas Studio UI Standard

The primary UI is an Engineering World, not a file tree or dashboard. The World Canvas is a bounded projection over ATLASX with semantic zoom: world -> territory -> system -> architecture -> component -> module -> symbol -> source.

Map layers may project architecture, code, capability, dependency, security, performance, evidence, provenance, design, execution, innovation and history. 3D geometry must encode declared projection meaning; coordinates and camera state are UI projection state, not engineering truth.

Source editing, design authoring, diff, terminal and agent interaction are views of the same semantic identities.
