# Atlas Decisions

Only durable architecture choices belong here. Temporary implementation history, migration notes and progress reports stay in Git history or non-canonical evidence.

A superseded decision must identify its successor. No historical fleet/mirror decision is currently canonical.

## Accepted decisions

- `0001-one-normalized-semantic-path.md` — all semantic producers converge through census → normalize → reconcile before graph/ATLAS projection.
- `0002-epistemic-status-model.md` — one canonical EpistemicStatus vocabulary; FactKind, EvidenceKind and Disposition remain separate.
- `0003-constraint-derivation-provenance.md` — Souffle's provenance pattern absorbed as an additive `ConstraintResult.derivation` field, projected into the engineering graph via `add_constraint_derivations`.
- `0004-semi-naive-dependency-closure.md` — datafrog's semi-naive delta-driven fixed point absorbed as `core::closure`, computing origin-labelled transitive dependency reachability in `census_cargo_workspace` (`DependencyClosureReport.reachability`, schema v4).
- `0005-native-blake3-content-digest.md` — BLAKE3's unkeyed hash mode absorbed natively as `core::identity::blake3`; every inventoried regular file carries a validated `blake3-256:` `ArtifactRecord.content_digest` from one bounded, verified read (inventory schema v2). Supersedes the genome record's native-port rejection for the unkeyed mode only.
- `0006-inventory-change-detection.md` — rust-analyzer vfs's Create/Modify/Delete taxonomy absorbed as `core::census::delta::diff_inventories` over BLAKE3 content identity; `systemize --previous` emits `inventory_delta` (report schema v13).
- `0007-three-valued-constraint-verdict.md` — `ConstraintVerdict { Satisfied, Violated, Unknown }` (strong Kleene conjunction) on every ADL constraint result; an undeclared required attribute is UNKNOWN (`ATLAS-E055`), not a violation; admission blocks on `ADL_CONSTRAINT_VIOLATED` and `ADL_CONSTRAINT_UNKNOWN` separately.
- `0008-extraction-derivation-cache.md` — persisted per-artifact `ExtractionBatch` memo keyed on BLAKE3 over the full extraction input, the digest of the bytes read, and a build digest of all extractor/core sources + `Cargo.lock`; used only when read bytes equal the inventoried digest; `systemize --cache`. Measured: reports byte-identical, but graph summarization (~95% of run time) — not extraction — is the recensus cost centre.
- `0009-indexed-graph-node-dedup.md` — `ensure_node` deduplicates through an incremental, non-serialized node-id index instead of a linear scan (append-only contract, shrink rebuild, debug sentinel); graph output byte-identical, `systemize` 187 s → 12.9 s (debug).
- `0010-physical-quantities-and-dimensional-constraints.md` — `core::quantity`: exact rational SI quantities over 8 base dimensions (angle separate); units with irrational/affine factors refused; ADL `require x.attr (==|>=|<=|>|<) <quantity>` compares by dimension and exact value (E056 dimension mismatch = VIOLATED, E057 unsupported unit = UNKNOWN, E058 ordering over non-quantity = UNKNOWN); 75/75 units agree with pint.
- `0011-visual-observation-record.md` — Creator Fabric's first primitive: hermetic browser observation (`atlas-systemizer observe`) → OBSERVED element geometry/style → DERIVED ratio-first layout relations with resolution-bounded uncertainty and interval-stated responsive rules; `contracts/CREATOR-FABRIC.md` fixes authorization/originality/epistemic rules.
- `0012-planar-arm-physical-model.md` — physical milestone 1: `core::physical::PlanarArm` from ADL Arm/Link/Joint entities with dimension-checked quantities; exact reach, inner radius and worst-case static shoulder torque (DERIVED, assumptions stated); requirement verdicts; FK verified vs closed form; `atlas-systemizer physical`; `contracts/PHYSICAL-ENGINEERING.md`.
- `0013-browser-as-instrument-breakpoint-bisection.md` — `observe --bisect`: responsive changes located to one pixel by re-observation (INFERRED, monotone-transition assumption stated); the fixture's `max-width: 699px` measured at exactly (699, 700) in 10 probes.
- `0014-cross-domain-drivetrain-power.md` — physical milestone 2: joint torque → motor torque (gear, efficiency) → holding current (k_t) → heat (I²R) → rail total and power, all exact and dimension-checked, every value naming its inputs; a heavier payload that keeps reach SATISFIED is caught VIOLATED at the power rail.
- `0015-interaction-stimuli-and-mechanisms.md` — `observe --interact`: hover/click/click-twice/focus stimuli in fresh hermetic contexts, settled after animations, diffed against baseline → OBSERVED changes → DERIVED mechanisms (HOVER_AFFORDANCE, DISCLOSURE with controlled elements, TOGGLE, FOCUS_INDICATOR) and a state graph.
- `0016-motion-curve-inference.md` — `observe --motion`: paused/seeked deterministic curve sampling of every hover animation; easing INFERRED from the curve alone against the CSS keyword curves (alternatives + residuals, overshoot flag), validated against the engine's declared timing (5/5 agree) and Chromium-sampled keyword values.
- `0017-creator-construction-loop.md` — `atlas-systemizer create`: ratio-first DesignIntent → deterministic placeholder-only HTML/CSS → rendered → re-observed through layout/bisection/stimuli/motion → every intended relation SATISFIED/VIOLATED/UNKNOWN; an original intent verifies 10/10, a tampered artifact fails exactly the tampered relations.
- `0018-design-genome-and-recombination.md` — `genome`: mechanisms (SPLIT_HERO, COLLAPSING_GRID, HOVER_LIFT) abstracted from observed references as small rational ratios with provenance; `create --genome --recipe`: recombination refused unless it draws on ≥2 sources and varies every mechanism, each parameter traced to inherited/varied/default, then created and verified.
- `0019-arm-dynamics-and-simulation.md` — ADR 0002 gains SIMULATED; closed-form 2R Lagrangian dynamics, minimum-jerk declared trajectories, computed-torque RK4 simulation with exact BLAKE3 run identity and a divergence guard; actuator capability decided on DERIVED inverse-dynamics demand, tracking on SIMULATED evidence; a fast move that passes every static check is caught.
- `0020-design-search-and-pareto-preservation.md` — `search`: deterministic originality-valid candidates over a genome, each created and verified; measured objectives with stated meanings (novelty, chars-per-line proxy, narrow content extent); only verified, fully measured candidates compete; the whole non-dominated set is kept, never a single "best".
- `0021-bounded-donor-working-set.md` — donor source is temporary working material: storage state orthogonal to decision state (11 states, presence rules), cheapest-sufficient materialization modes, measured disk watermarks + budget (available − build headroom − safety reserve) + working-set cap gate every materialization; accounted dependencies are not cloned; storage integrity enforced; clone-first superseded.
- `0022-browser-instrument-abstraction.md` — browser engines are replaceable instruments: `BrowserInstrument` (capabilities, explicit availability/unsupported), instrument-declared layout resolution and network policy, W3C WebDriver backend (chromedriver verified, Ladybird harness-ready but build-blocked), `EngineDifferentialReport` (layout/breakpoints/interactions, unclassified until investigated, same-engine never reported as independent), `CREATOR-INSTRUMENTS.toml` registry + promotion gate.
- `0023-product-semantic-ir-and-unit-economics.md` — PRODUCT_FOUNDRY first slice: ADL-declared Product IR (hypothesis, variant, SKU, BOM, cost items/rates, price, quote, requirement), exact money intervals with an evidence basis on every value, dependency-aware unit economics to break-even, interval-decided requirements; estimates without uncertainty/source refused, QUOTED requires a Quote, UNKNOWN never zero, no silent currency conversion; oracle-exact on the desk-organizer fixture.
- `0024-self-recensus-proof-of-nextgen.md` — PRIORITY RESET: P0 census closure .. P6 construction canonical (PRIORITY.toml), secondary families frozen; self-recensus (revision-independent CensusSnapshot, intent-vs-observation proof with forbidden regressions and deterministic replay) mandatory and chained for every generation from G57.
- `0025-census-certificate.md` — CensusCertificate v2 computed from the census (schema-conformant, typed blockers, state follows blockers); self-scope CENSUSED: provenance incomplete (230 facts w/o revision, 120 w/o extractor), atlas-cli workspace member outside inventory, single-engine extraction, 8 UNKNOWN coverage dimensions, no .atlas root.
- `0026-adl-consumes-census-truth.md` — exit criterion C: authored `depends_on` reconciled against the Cargo dependency census by materialization path (SATISFIED / ATLAS-E060 / E061 / E062; uncheckable relations are explicit deltas); census truth the authored ADL lacks is derived as `.atlas/declared/census.adl` with a drift gate.
- `0027-minimum-atlas-census-container.md` — exit criterion D: ATLAS wire v1 writer/reader/validator for an explicitly unsealed census container (facts, obligations, declared ADL graph, certificate); pinned varint/wire-type/flag/schema-id/root-identity encodings; transactional publication; the certificate names the verified root as ATLAS_ROOT_UNSEALED, never SEALED.
