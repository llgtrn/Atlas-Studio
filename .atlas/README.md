# Atlas Studio Knowledge Root

.atlas/ is the sole repository knowledge and control root for Atlas Studio.

Active engineering chain: ADL plus admitted source and donor evidence -> secure ingestion -> corpus.atlas -> semantic compilation -> world.atlasx -> query, synthesis, materialization and verification.

Keep durable architecture, contracts, donor census, provenance, licenses and verified evidence here. Rebuildable scans and reports belong in .atlas/.cache/. Donor checkouts belong in .atlas/temporary/.
