# Atlas Architecture Router

Atlas Studio is one engineering system with four implementation responsibilities: core, runtime, adapter and apps/ui.

Read the North Star for destination, SYSTEM for ownership, INVENTION-PIPELINE for learning and invention, and the system blueprint/contract for sequencing and hard invariants. Historical fleet, mirror-worker and Chronica-specific operating models are not canonical Atlas architecture.
