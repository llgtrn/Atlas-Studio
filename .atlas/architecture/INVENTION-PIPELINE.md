# Invention Pipeline

Atlas does not census OSS to copy repositories. It moves through implementation -> mechanism -> principle -> tradeoff -> limitation -> technology gap -> candidate synthesis -> experiment -> validated native technology.

Census operates from source span/function/file/module through repository, technology family and corpus scope. Expensive analysis is adaptive and evidence-driven.
