# Atlas Studio North Star

Atlas Studio is a product-neutral engineering-world compiler and system invention environment. It studies source, OSS technology, design systems, specifications and evidence; compresses them into a secure engineering corpus; compiles that corpus into a typed semantic world; and uses that world to design, implement and verify better native systems.

Canonical chain: intent and ADL + admitted source and donor evidence -> ATLAS binary corpus -> ATLASX semantic engineering world -> compare, synthesize and invent -> materialization IR -> Rust and TypeScript -> tests and evidence.

Hard invariants: backend/compiler/runtime is Rust; frontend is TypeScript/TSX until evidence justifies change; .atlas is the sole knowledge root; donors are untrusted evidence rather than authority; ingestion is not execution; important claims preserve provenance and epistemic status; rebuildable projections are not truth; AI output is candidate until verified; native technology cannot require donor runtime availability.

Sequencing: secure admission -> source intelligence -> ATLAS reader/writer -> incremental corpus -> ATLASX compiler -> query/link/inference -> synthesis/materialization -> verification -> World Canvas.
