# Evidence

This directory is for durable proof deliberately admitted to Git: verification summaries, attestations, benchmark conclusions, integrity records and compact evidence manifests.

Evidence must retain provenance, temporal/revision identity and epistemic class. Evidence may support or contradict a claim; contradiction is first-class.

Large source observations, rebuildable repository/federation graphs, temporary plans, Atlas/AtlasX inspection exports and scan outputs belong in `.atlas/.cache/` or the binary artifact pipeline rather than being committed as giant JSON/Markdown truth stores.
